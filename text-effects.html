Text-Overflow

1) Clip

In clip if there is a single long line which cannot be fitted in a particular width then clip will Cut the line from where width is ending and it wont look as if there is a long text

1) ellipsis

In ellipsis if there is a single long line which cannot be fitted in a particular width then ellipsis will Cut and add ... there so that it is understandable that there is more text
