CSS object-fit Showcase

A responsive layout displaying how the same images respond differently depending on the explicit value of the CSS object-fit property inside matching aspect-ratio container spaces.

Mountain Peak cover

Crops the image intelligently to completely fill its container space while preserving original aspect ratio.

Mountain Peak contain

Letterboxes or pillarboxes the image so the entire file scales down cleanly to sit fully visible inside constraints.

Industrial Wire fill

Ignores original file aspect ratio entirely, stretching or squishing pixels forcefully to match container boundaries perfectly.

Industrial Wire none

Completely drops scaling. The image acts at its native source resolution sizing, keeping only the center portion visible.

Deep Forest cover

Demonstrates a native portrait file fitting perfectly into our landscape-oriented row layout without distortion.

Deep Forest contain

The same portrait asset, revealing the empty background margins left on the left and right sides to avoid cropping.
